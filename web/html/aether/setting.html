Automated Let's Encrypt SSL via Certbot

Aether VPN integrates directly with Certbot to issue and automatically renew free Let's Encrypt certificates. Certificates are automatically deployed to the panel database and web server with zero manual file copying.

Run Certbot Wizard on Server:
aether-vpn certbot
Certbot automatically registers renewal hooks in /etc/letsencrypt/renewal-hooks/deploy/aether-vpn.sh to re-apply certificates before expiration.
